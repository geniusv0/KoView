# KoView 설치

Windows 64비트용 KoView 1.0.28 설치 파일입니다.

**[MSI 설치 파일 다운로드](https://github.com/geniusv0/KoView/raw/refs/heads/main/Installer/KoView-1.0.28-win-x64.msi)**

다운로드한 `KoView-1.0.28-win-x64.msi`를 실행하세요. .NET 10 LTS 런타임이 포함되어 있습니다.

[최신 릴리즈와 포터블 ZIP](https://github.com/geniusv0/KoView/releases/latest)에서도 다운로드할 수 있습니다.

설치 파일은 미서명 상태입니다. 엔진 라이선스와 대응 소스 검토 상태는 [릴리즈 설명](https://github.com/geniusv0/KoView/releases/tag/v1.0.28)에서 확인하세요.
